## Project Description
This project is a console-based **Tic-Tac-Toe game** implemented in C for **two human players**.  
Players take turns marking X and O on a 3x3 board until one player wins or the game ends in a draw.  

### Key Features
- 3x3 game board  
- Turn-based gameplay for two players  
- Automatic winner and draw detection  
- Simple and clear console interface
